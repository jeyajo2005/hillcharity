## How to Run Locally
Run `start.bat` or run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
You can also double-click `index.html` to open directly in your browser.

## How to Deploy to Netlify
- **Publish directory**: `.` (Root directory)
- **Build command**: Leave blank (this is a pre-compiled static distribution)
- `_redirects` and `netlify.toml` are already included to handle SPA client-side routing (`/* -> /index.html 200`).
